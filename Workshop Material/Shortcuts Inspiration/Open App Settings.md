# Open Settings of Current App

**Quick Action** · Jump to any app's settings page

Some settings can only be changed in the Settings app - most notably the "Paste from Other Apps" clipboard permission, which must be set to "Allow" in an app's settings page to stop the constant paste confirmation prompts. Other examples include notification permissions, location access, or the app-specific language setting. This shortcut takes you directly to an app's settings page without scrolling through the Settings app manually.

## What It Does

A shortcut that opens the Settings app at a specific app's page using the `App-prefs:` URL scheme.
