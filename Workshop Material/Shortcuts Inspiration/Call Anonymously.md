# Call Anonymously

**Quick Action** · Hide your caller ID with a number prefix

Most cellular providers support a special prefix you can dial before a phone number to hide your caller ID for that specific call. The standard GSM code `#31#` works across most of Europe - including Finland, Germany, and the Nordics. Notable exceptions are the UK (`141`) and the US (`*67`). A [full list of codes by country](https://www.wikiwand.com/en/articles/Caller_ID#Disabling_caller_ID_delivery) is available on Wikipedia.

## What It Does

A shortcut that asks for a phone number (or lets you pick a contact), prepends the anonymous calling prefix, and dials. No need to remember the code or type it manually every time.

## Taking It Further

- Let the user choose between a contact and a manually entered number
