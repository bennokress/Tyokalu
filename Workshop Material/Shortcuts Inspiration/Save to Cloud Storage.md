# Save to Cloud Storage

**Share Sheet** · Sorts files by type before uploading

You receive all kinds of files throughout the day - PDFs from email, photos from messages, documents from the web. Instead of dumping everything into one folder in your cloud storage, this shortcut sorts files into the right place automatically.

## Example

A Share Sheet shortcut that accepts files and sorts them into your cloud storage based on file type:

- **PDFs** → `Documents/PDFs/`
- **Images** → `Photos/Imports/`
- **Videos** → `Videos/Imports/`
- **Audio files** → `Music/Imports/`
- **Everything else** → Prompt you to pick a folder

Where each file type ends up depends entirely on your personal preference and which types you handle repeatedly in the same way. The shortcut could also rename files with a date prefix for consistent organization and show a confirmation with the destination path.

## Taking It Further

You could combine this with [Save for Later](Save%20for%20Later.md) into a single "Save" shortcut that first checks whether the input is a URL or a file, then branches accordingly. That way you have one universal save action in your Share Sheet.
