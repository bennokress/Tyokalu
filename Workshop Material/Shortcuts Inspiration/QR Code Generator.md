# QR Code Generator

**Quick Action** · Generate a QR code from any text or URL

Whether you want to share a Wi-Fi password, a link, or contact details - a QR code is often the fastest way to get information from one device to another.

## What It Does

A shortcut that takes text input (typed, from the clipboard, or via the Share Sheet), generates a QR code image, and lets you share or save it. Shortcuts has a built-in action for generating QR codes, so the logic is straightforward.

## Taking It Further

- Offer presets for common use cases: URLs, plain text, Wi-Fi credentials
- Speaking of Wi-Fi, the QR format to let someone join a network immediately is `WIFI:T:WPA;S:NetworkName;P:Password;;`. Bonus points for including a list of your most shared networks (probably your home network) ready to go, so you don't have to type out the password every time you want to share it. And extra points for taking precautions to not share that password with anyone you might share the shortcut itself with - that's possible by using the Import Questions feature or a separate app like [Data Jar](https://apps.apple.com/app/id1245356019) for your secrets.
